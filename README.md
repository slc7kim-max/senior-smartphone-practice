# 시니어 스마트폰 기초연습장 · 부산스마트IT봉사단

어르신(시니어) 수강생이 스마트폰의 기본 손동작을 마음 편히 연습할 수 있는 웹 연습장입니다.
설치 없이 휴대폰 브라우저로 주소만 열면 바로 연습할 수 있습니다.

## 연습장 주소

**https://slc7kim-max.github.io/senior-smartphone-practice/**

## 연습 코스 (4단계)

1. **톡 누르기** — 화면의 동그라미를 5번 눌러 봉투를 채웁니다.
2. **꾹 누르기 · 옆으로 밀기 · 글씨 키우기** — 손가락을 1초간 꾹 누르기, 카드 넘기기, 글씨 크기 4단계 바꾸기.
3. **글자 입력** — 따라 쓰기 3문장, 확인 버튼, 그리고 말로 입력하는 방법 안내.
4. **자주 쓰는 아이콘 스위치** — 와이파이·소리·손전등·밝기·블루투스·알람·방해 금지·비행기 모드를 켜고 끄기.

모든 연습은 실패해도 휴대폰 설정이 바뀌지 않는 안전한 화면이며, 진행 상황은 그 브라우저에만 저장됩니다.

## 수업에서 쓰는 방법

- 카카오톡·문자로 위 주소를 보내면 수강생이 눌러서 바로 열 수 있습니다.
- 첫 화면에서 연습을 고르고, 각 코스 끝의 **← 처음 화면**으로 돌아옵니다.
- 아이폰·안드로이드 모두 같은 주소로 동작합니다.

## 파일

- `index.html` — 연습장 전체(HTML·CSS·JS가 한 파일에 들어 있어 외부 연결이 필요 없습니다).
